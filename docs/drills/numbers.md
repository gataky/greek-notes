# Numbers

Three kinds of question: write a number in Greek, read one back as digits, and count things, where 1, 3, 4, the hundreds and χίλιοι agree with the noun (τρεις γυναίκες, τρία παιδιά). Chips pick the kinds and the size of the numbers.

See [Numerals](../grammar/numerals.md) for the notes behind this drill, or [open the drill on its own page](../apps/numbers.html).
