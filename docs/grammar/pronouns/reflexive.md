# Reflexive and Emphatic Pronouns

English "-self" covers three things that Greek keeps apart:

| English | Greek | Meaning |
| --- | --- | --- |
| I blame myself. | Κατηγορώ **τον εαυτό μου**. | The action comes back to you |
| I made it myself. | Το έφτιαξα **ο ίδιος**. | You, and nobody else |
| I live by myself. | Μένω **μόνος μου**. | Alone, unaided |

## ο εαυτός μου: myself

It's a masculine singular noun whoever it refers to. The article and ending change with case, and μου, σου… change with the person. Even with a plural owner it usually stays singular.

| English | Greek |
| --- | --- |
| myself | τον εαυτό μου |
| yourself | τον εαυτό σου |
| himself, herself, itself | τον εαυτό του, της, του |
| ourselves | τον εαυτό μας |
| yourselves | τον εαυτό σας |
| themselves | τον εαυτό τους |

| English | Greek |
| --- | --- |
| She talks to herself. | Μιλάει **στον εαυτό της**. |
| Do you believe in yourself? | Πιστεύεις **στον εαυτό σου**; |
| I'm not myself today. | Δεν είμαι **ο εαυτός μου** σήμερα. |

**Everyday actions use a passive verb instead**: **πλένομαι** (I wash myself), **ντύνομαι** (I get dressed). See [passive verbs](../passive-verbs.md#type-2-reflexive).

## ο ίδιος: myself, the same

ο ίδιος, η ίδια, το ίδιο declines like ωραίος. It agrees with whoever it refers to, so a woman says **η ίδια**.

| English | Greek |
| --- | --- |
| I'll tell him myself. | Θα του το πω **ο ίδιος**. |
| Maria herself told me. | Μου το είπε **η ίδια η** Μαρία. |
| We have the same car. | Έχουμε **το ίδιο** αυτοκίνητο. |
| It's all the same to me. | **Το ίδιο** μου κάνει. |

**The second article changes the meaning**: **ο ίδιος άντρας** is "the same man", **ο ίδιος ο άντρας** is "the man himself".

## μόνος μου: by myself

μόνος agrees with the subject, and μου, σου… show the person. Without them, μόνος is just "alone".

| English | Greek |
| --- | --- |
| I live by myself. | Μένω **μόνος μου**. (woman: **μόνη μου**) |
| Did you do it on your own? | Το έκανες **μόνος σου**; |
| We'll go on our own. | Θα πάμε **μόνοι μας**. |

## Each other

Many verbs use a passive form: **βλεπόμαστε** (we see each other). See [passive verbs](../passive-verbs.md#type-3-reciprocal). Otherwise, use **ο ένας τον άλλο**. Each part agrees with the people involved.

| English | Greek |
| --- | --- |
| We help each other. | Βοηθάμε **ο ένας τον άλλο**. |
| The two sisters help each other. | Οι δύο αδερφές βοηθάνε **η μία την άλλη**. |
| They talk to each other. | Μιλάνε **ο ένας στον άλλο**. |
| They talk among themselves. | Μιλάνε **μεταξύ τους**. |
