# Interrogative Pronouns

Three words ask nearly every pronoun question: **ποιος** (who, which), **τι** (what) and **πόσος** (how much, how many). Only τι never changes.

## Examples

| English | Greek |
| --- | --- |
| Who is it? | **Ποιος** είναι; |
| Who did you see? | **Ποιον** είδες; |
| Who are you talking to? | Με **ποιον** μιλάς; |
| Which bus goes to the centre? | **Ποιο** λεωφορείο πάει στο κέντρο; |
| Whose is this bag? | **Τίνος** είναι αυτή η τσάντα; |
| What do you want? | **Τι** θέλεις; |
| What time is it? | **Τι** ώρα είναι; |
| What are you writing with? | Με **τι** γράφεις; |
| How much is it? | **Πόσο** κάνει; |
| How many children do you have? | **Πόσα** παιδιά έχεις; |
| How old are you? | **Πόσων** χρονών είσαι; |

- **ποιος or τι before a noun?** ποιος picks from a known set, τι asks what kind: **ποιο** κρασί θέλεις; (which wine?), **τι** κρασί θέλεις; (what kind of wine?).
- **"What is your…?" is often ποιος**, agreeing with the noun: **Ποιο** είναι το τηλέφωνό σου; **Ποια** είναι η διεύθυνσή σου;
- **Prepositions go first**, never at the end: **με** ποιον; (who with?), **για** ποιον; (who for?).
- **Indirect questions use the same words**: Δεν ξέρω **ποιος** ήρθε (I don't know who came).
- **πού, πώς, πότε, γιατί** ask where, how, when and why. They're adverbs, so they never change.
