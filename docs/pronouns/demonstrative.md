# Demonstrative Pronouns

**αυτός** covers both "this" and "that", and is also the everyday "he, she, it". **εκείνος** is for something further off or in contrast.

| English | Greek |
| --- | --- |
| This wine is good. | **Αυτό το** κρασί είναι καλό. |
| I like that house. | Μου αρέσει **εκείνο το** σπίτι. |
| This is Maria. | **Αυτή** είναι η Μαρία. |
| These are my keys. | **Αυτά** είναι τα κλειδιά μου. |
| This one here or that one there? | **Αυτό** εδώ ή **εκείνο** εκεί; |
| That's why I left. | Γι' **αυτό** έφυγα. |

- **The article stays**: **αυτό το** βιβλίο or **το** βιβλίο **αυτό**, never "αυτό βιβλίο".
- **It agrees with the noun it points to**, where English says "this" for anything: **αυτή** είναι η Μαρία, **αυτός** είναι ο Νίκος.
- **The genitive mostly goes with a noun**: το όνομα **αυτού** του ανθρώπου (this person's name). For plain "his, her", use [του, της](possessive.md).
- **τούτος**, -η, -ο means "this one here". You'll meet it in older writing and some regional speech.

## τέτοιος, τόσος: such, so much

| English | Greek | Example |
| --- | --- | --- |
| such, like this | τέτοιος, τέτοια, τέτοιο | Δεν έχω δει **τέτοιο** πράγμα. (I've never seen such a thing.) |
| so much, so many | τόσος, τόση, τόσο | Έχω **τόση** δουλειά! (I have so much work!) |

**τόσο** alone is the adverb "so": είναι **τόσο** ωραία (it's so nice).
