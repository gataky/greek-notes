# Indefinite Pronouns

These refer to no one in particular: *someone, nothing, everyone*. They pair up with the question words:

| | People | Things |
| --- | --- | --- |
| who?, what? | ποιος | τι |
| someone, something | κάποιος | κάτι |
| no one, nothing, anyone, anything | κανένας | τίποτα |
| everyone, everything | όλοι | όλα |
| whoever, whatever | όποιος | ό,τι |

## κάποιος, κάτι: someone, something

κάποιος, κάποια, κάποιο declines like ωραίος. κάτι never changes. Both also go with a noun.

| English | Greek |
| --- | --- |
| Someone's at the door. | **Κάποιος** είναι στην πόρτα. |
| I'll come some day. | Θα έρθω **κάποια** μέρα. |
| I want something to eat. | Θέλω **κάτι** να φάω. |
| someone else, something else | κάποιος άλλος, κάτι άλλο |

## κανένας, τίποτα: no one, nothing

κανένας is built on [ένας](../greek-numerals.md#which-cardinals-decline) and has no plural. τίποτα (also τίποτε) never changes.

| | Masculine | Feminine | Neuter |
| --- | --- | --- | --- |
| Nom. | κανένας, κανείς | καμία, καμιά | κανένα |
| Acc. | κανέναν | καμία, καμιά | κανένα |
| Gen. | κανενός | καμίας, καμιάς | κανενός |

| English | Greek |
| --- | --- |
| Nobody came. | Δεν ήρθε **κανένας**. |
| I have no problem. | Δεν έχω **κανένα** πρόβλημα. |
| I don't want anything. | Δεν θέλω **τίποτα**. |
| Who was it? Nobody. | Ποιος ήταν; **Κανένας**. |
| Did anyone call? | Πήρε **κανένας** τηλέφωνο; |
| Do you have any idea? | Έχεις **καμιά** ιδέα; |
| Do you want anything? | Θέλεις **τίποτα**; |

- **The verb still needs δεν or μην**, so Greek says "I didn't see nobody": **δεν** είδα **κανέναν**.
- **In a question they mean "any"**, with no negative word: Θέλεις **τίποτα**; **κάτι** asks more neutrally: Θέλεις **κάτι**;
- **Before a number, καμιά is "about"**: **καμιά** δεκαριά (about ten). See [numerals](../greek-numerals.md).

## Each, all, other

| English | Greek | Example |
| --- | --- | --- |
| every, each | κάθε | **Κάθε** μέρα πάω στη δουλειά. |
| everyone, each one | ο καθένας, η καθεμία, το καθένα | **Ο καθένας** έχει τη γνώμη του. |
| all, whole | όλος, όλη, όλο | Δούλεψα **όλη** τη μέρα. |
| other, another, else | άλλος, άλλη, άλλο | Θέλεις κάτι **άλλο**; |
| some, a few | μερικοί, μερικές, μερικά | **Μερικοί** φίλοι μου μένουν εκεί. |
| both | και οι δύο, και τα δύο | **Και οι δύο** ήρθαν. |

- **κάθε never changes** and needs a noun. ο καθένας stands alone.
- **όλος keeps the article**: όλ**οι οι** φίλοι μου, όλ**ο το** βράδυ.
- **ο ένας… ο άλλος** is "one… the other". **Την άλλη** εβδομάδα means "next week".
