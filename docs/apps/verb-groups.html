Where you slip

    The trick
    • The simple future, να and the simple past all use the perfective stem: θα γράψω, να γράψω, έγραψα. Learn it once, use it three times.
    • Most perfective stems add σ, and the σ merges with the sound before it. Lip sounds (π, β, φ) + σ = ψ. Throat sounds (κ, γ, χ) + σ = ξ. Tooth sounds (τ, δ, θ, ζ) vanish into σ.
    • Say each pair out loud: Γράφω κάθε μέρα. Αύριο θα γράψω.
    • Each verb's fork, with the letters that change, is on the aspect forks page.
